Components

Every component in the system: the shared primitives, then each page's own components. Each shows a live example (rendered under the header selectors) alongside a framework-neutral spec of its structure, tokens, states and behaviour. The values are the prototype's, quoted verbatim from design-system.css; each token's per-theme value is on the Tokens page.

Foundation components read only token keys, so they are correct in all four themes and all four colourblind modes; page-specific components use tokens only. Two house rules apply to everything here: one global focus ring (2px --cyan, 2px offset, on keyboard focus), and small icon buttons pad invisibly to a 44px hit target.
