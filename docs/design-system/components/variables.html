Variables page .var-row, .ref-box, .live-value

The shared variable table, its detail column, and the write/read reference boxes.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: hover, selected, problem; the full catalogue is on the states page.

Components

var:fn 0 1 bnd-fn bnd-alt-btn ×
bnd-fn bravo button:30 · Modifier
A selected variable table row (writers and readers as pills) and a write reference box.

Row .var-row

  • A six-column grid (name 150 / init 64 / live 56 / writers 1.15 / readers 1.35 / remove 24, 14 column gap)
  • Under an uppercase 10.5px head
  • Hover: --inset
  • .selected fills --cyan-bg with a 2px inset --cyan left bar
  • Name (.vname) mono 13 600; init (.vinit) mono 12.5 --text-2
  • Live (.vlive) mono 12.5 600 --green (an .off value drops to 400 --text-3)
  • The writers and readers cells (.vrefs) wrap 10.5px mono pills, violet for writes and cyan for reads
  • An empty writes cell renders a .chip.warn "nothing writes it" and an empty reads cell an italic .vnone

Remove .row-del

  • A 22px hover-revealed remove
  • Amber on hover, a 44px hit area, always visible at 640

Reference box .ref-box

  • --inset / --line, radius 8, 9/12 padding, --shadow-0, contents 10 apart
  • The reference id (.ref-id) is mono 12.5 600 coloured by role
  • The description (.ref-desc) is 12px --text-3, ellipsized

Live value .live-value

  • 22px 700 --font-mono in --green with a 12px .live-note
  • The .off form is 16px 400 --text-3 reading "waiting for a write"

Phase chip .phase-chip

  • 11px 600, --chip-*, radius 999, 1/7 padding
  • Marks "phase 2" on tabs and card heads

Legend .legend

  • 8px .swatch squares (violet write, cyan read)
  • A right-aligned .lg-note

Remove action .remove-action

  • The full-width destructive CTA
  • Radius 10, 10 padding, 13px 600, --shadow-0, 24 above
  • Hover amber border, text and icon
