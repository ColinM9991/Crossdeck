States and behaviour

States and behaviour

Every visual state in the system and what triggers it.

Hover

Trigger: Pointer over

  • Borders move to --hover-line (cards, pills, secondary buttons, device/profile cards)
  • Fills move to --inset (rows, picker rows, rail items)
  • Outline buttons fill --cyan-bg
  • The primary button brightens to 1.06
  • Links underline
  • Plus/delete marks fade in
  • Destructive marks turn amber

Active

Trigger: The item is the current one

  • The cyan treatment: rail items (fill + indicator bar)
  • Tabs and segments (--seg-active)
  • Outline/secondary buttons (cyan fill)
  • Pills

Selected

Trigger: The user has selected it, mirrored in the detail pane

  • List cards and binding rows: a --cyan-line border + --selected-bg fill (cards)
  • Or a --cyan-bg fill + 2px inset --cyan left bar (rows)
  • Variable table rows the same

Disabled

Trigger: The control is disabled

  • Buttons: not-allowed pointer
  • .btn.add at 0.4 opacity with no background
  • Tabs in --tab-disabled
  • Already-added aircraft options are disabled

Problem

Trigger: Data indicates an error (left-out counts, unknown refs)

  • Amber marks on broken items: .ctrl.problem, .when.problem, .stat.amber, .note-line (warn default), .status-pill.warn, .chip.warn, .guard-help.problem
  • The .problem-line banner renders when a count is above zero

Pulsing

Trigger: The value just changed; all motion stops under reduced motion

  • The unsaved counter scales (0.45s) on each change
  • The newest monitor row .flash (0.9s cyan fade)
  • The learn note's static cyan dot

Hidden

Trigger: No content, or nothing to report

  • The import zone, pickers, modal, save hints, notes, detail blocks and the monitor's unsaved counter hide when there is nothing to show
  • Hover-revealed marks (.row-del, .pplus, .src-del) are invisible until the parent is hovered and forced visible at 640
  • The top-bar warn pill and problem line disappear when nothing is left out

Focus

Trigger: Keyboard focus

  • One global ring (2px --cyan, 2px offset)
  • The switch shows it on the track
  • Activatable elements respond to Enter/Space
  • The settings nav roves with the arrow keys
  • The editor's tabs follow the standard tabs pattern
  • The screen segments announce a pressed/unpressed state

Reflow

Trigger: The viewport narrows (1180 / 900 / 640)

  • 1180 wide: columns stack into rows, the rail narrows to 80
  • 900 wide: stat rows go two across
  • 640 wide: a single column, the top bar wraps, the rail becomes a fixed bottom nav, tap targets are 44, and the body reserves 66 of bottom padding
  • A wide-preview mode widens the detail column when a preview is present
