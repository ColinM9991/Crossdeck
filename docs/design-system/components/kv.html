Key-value rows .kv

Label-left, value-right rows that fill card bodies and detail panes.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

Anatomy

Devicesbravo, pap3, mcdu
Bindingsbound controls12
Last applied2 h ago
The three shared value variants: plain, .mono and .dim; .k .desc adds a muted line under a key.

Row .kv

  • Label and value on one line, 12 apart, 11/16 padding
  • A 1px --line-soft divider between consecutive rows

Key .k

  • Fixed 96 wide (72 at 640), 12.5px in --text-2
  • An optional .k .desc second line sits beneath it, 11.5px --text-3, 2 down

Value .v

  • Pushed to the right edge, 13px, ellipsized at 60% width, single line
  • .v.mono is 12.5px --font-mono
  • .v.dim is --text-3 (the profiles and devices pages also italicize it)

Page additions

  • .v.chips (devices) wraps and holds mono 10.5px pills 6 apart
  • The editor's .v splits a preview value into .eval-dim (the input, --text-3), an .arrow (--text-3) and .out (the result, --text)
