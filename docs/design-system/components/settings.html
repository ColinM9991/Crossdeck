Settings page .nav-item, .set-row, .switch

The settings page's own controls: a section nav column, label-left / control-right rows, the switch, and the chevron select.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: hover, active, problem, hidden; the full catalogue is on the states page.

A section nav item and a label-left / control-right setting row with the switch in the checked state.

Nav item .nav-item

  • A 44 minimum height section selector: 9/12 padding, radius 8, 13px --text-2
  • Hover --text on --inset
  • The active item is --cyan on --cyan-bg at 600
  • The nav column is a radio group that roves with the up/down arrow keys
  • At 1180 wide the column becomes a wrapping row

Setting row .set-row

  • Label and control 12 apart, 13/16 padding, a divider between rows
  • The label block (.lbl) holds a title .t (13px 600) over a description .d (12px --text-3)
  • The control (.ctl) pins to the right edge (value-only rows use .val, mono 12.5px)
  • At 640 the row wraps and the control goes full width

Switch .switch

  • A 38x21 track (--inset / --line, radius 999) with a 15px thumb (--text-3, 3 in from the left)
  • Checked: the track is --cyan-bg / --cyan-line and the thumb is --cyan, moved 17 across
  • Keyboard focus shows the ring on the track; an invisible 44px hit area
  • A 0.15s transition that stops under reduced motion

Save hint .save-hint

  • The amber box variant on this page: --amber-bg / --amber-line, radius 8, 9/13 padding, 12px --amber, with a 6px amber dot and a 600 count
  • Hidden at zero
  • The variables, profiles and devices pages use a lighter centred text variant (11.5-12px --text-3, amber dot and count)
