Notes and callouts .note-line, .problem-line, .conn-note, .learn-note

Advisory strips. The amber ones need attention; the neutral and cyan ones inform. All are single-line rows with an icon or dot lead-in.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: problem, pulsing; the full catalogue is on the states page.

The note and callout types: the amber problem banner, warn and info note lines, the neutral connection note, and the cyan learn note.

Problem line .problem-line

  • An amber mono banner: --amber-bg / --amber-line, radius 8, 9/12 padding
  • 12px --font-mono in --amber, 12/16/14 margins
  • The text (.txt) ellipsizes and a trailing action sits at the right edge
  • Wraps at 640

Note line .note-line

  • Warn by default: amber family, 10/12 padding, 12.5px, 1.5 line height, --text-2 text with an amber icon
  • .info: --inset background, --line border, --text-3 icon
  • A .fixes action row (gap 14, 6 below) holds bold links; a .ghost link is --text-3
  • The editor page gives it a 14 bottom margin

Connection note .conn-note

  • Neutral: --inset / --line-soft, 9/13 padding, 12.5px --text-3

Learn note .learn-note

  • Cyan: --cyan-bg / --cyan-line, 9/13 padding, 12.5px
  • A static 7px .pulse dot and a trailing link at the right edge
