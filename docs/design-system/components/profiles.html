Profiles page .profile-card, .import-zone, .open-action

The profile list card and the detail pane's actions.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: hover, selected, problem, hidden; the full catalogue is on the states page.

Profile card .profile-card

  • Card surface, 1px --line, radius 10, 13/15 padding, 12 below, --shadow-0
  • Hover border --hover-line
  • .selected takes a --cyan-line border and --selected-bg fill (mirroring the detail pane)
  • The top row (.top) is 9 apart with the name (14 600) and a pill at the right edge
  • The meta line (.meta) is mono 11.5 --text-3
  • The description (.desc) is 12 --text-2 (an .empty description is italic --text-3)
  • The foot (.foot) is 9 apart, 10 below, with .count tags in 11.5 --text-3

Import zone .import-zone

  • A dashed --cyan-line import panel on --cyan-bg
  • Radius 10, 18 padding, centred 12.5px --text-2 with a cyan icon and a mono 11.5 .src caption
  • Hover a solid cyan border
  • Hidden by default, opened by the Import button or an ?import=1 parameter

Filter row .filter-row

  • 10 apart; a 11px 600 --text-3 label and a full-width input
  • Stacks at 640
  • Shared with the devices and editor pages

No match .no-match

  • 14/16, 12.5px --text-3: "No profiles match the filter."

Open action .open-action

  • The full-width accent CTA
  • 1px --cyan-line, --cyan-bg fill, --cyan text, radius 10, 10 padding, 13px 600, centred and 8 apart, 18 above
  • Hover brightens to 1.08
  • Reused on the devices page

Action row .action-row

  • A link row: 14 apart, 12 above
  • Links 12.5px 600 --text-3 hovering to --text-2
  • A .danger link hovers to --amber
  • .push right-aligns the last item (Delete)

Aircraft group

  • An .aircraft-list that wraps 7 apart
  • An .aircraft-chip is a violet-family pill (mono 12 600, 3/5/3/11 padding) with a 16px round .rm remove button (a 44px hit area, amber on hover)
  • An .aircraft-empty note is italic --text-3
  • .aircraft-add is a select row 10 below

Runtime state .runtime-state

  • Inline status in the Runtime card: an 8px .dot plus a 600 label
  • .runtime-running in --green, .runtime-stopped in --text-3
