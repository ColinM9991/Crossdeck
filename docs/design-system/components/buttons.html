Buttons and links .btn, .link

Every action in the app. Actions are buttons, never dead anchors.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: hover, active, disabled, problem; the full catalogue is on the states page.

Variants

Every action style: primary, outline, secondary, the smaller add button (including disabled), and the link and ghost-link actions.

Base

  • Contents 8 apart, radius 8, 8/15 padding, 13px 600, single line
  • At 640 wide the minimum height is 44

Primary .primary

  • Filled --cyan, text --on-accent
  • Hover brightens to 1.06

Outline .outline

  • --cyan text on a --cyan-line border
  • Hover and the active state fill --cyan-bg

Secondary .secondary

  • --card background, --line border
  • Hover border --hover-line; the active state takes the cyan treatment

Add .add

  • The smaller "+ New" companion: 7/13 padding, 12.5px
  • Disabled: 0.4 opacity with no background

Link .link

  • --cyan, 12.5px 600, 24 minimum height, underline on hover
  • The .ghost variant is the muted form: --text-3, hover --text-2

Destructive

  • There is no red in the system
  • Destructive actions are the neutral controls that turn to the warn role on hover
  • The per-row delete marks (.row-del, .src-del, .card-del) hover to --amber on --amber-bg
  • The full-width .remove-action CTA (see Variables) hovers to an amber border, text and icon
