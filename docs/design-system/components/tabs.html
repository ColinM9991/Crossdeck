Tabs .tab-row, .tab

Segmented page/section tabs. They render as pills on a bare canvas rather than bare text, because text tabs blend into the background in every theme.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: active, disabled; the full catalogue is on the states page.

Anatomy

Active, inactive and disabled tabs, a count badge, and the phase-2 chip on a disabled tab.

Row .tab-row

  • The tab strip: tabs 4 apart, a 1px --line-soft bottom edge, 14 below

Tab .tab

  • 6/12 padding, 12.5px 600 in --text-2, --inset background, 1px --line-soft, radius 6
  • A .tab-count badge is 11px 500 --text-3, 5 to the right of the label

Active .tab.active

  • --seg-active background, --line border, --text
  • The count moves to --text-2

Disabled .tab.disabled

  • Not-allowed pointer, colour --tab-disabled

Behaviour

Keyboard

  • The editor groups them in a list with the standard tabs keyboard pattern (arrow-key movement, roving focus)
