Monitor page .event-row, .kind-chips

The live event stream: a filter bar with kind pills and summary numbers, plus one row per input event.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: hover, active, problem, pulsing; the full catalogue is on the states page.

Filter row .filter-row

Kind chip .kind-chip

  • A pill (.chip) used as a filter toggle: inactive at 0.45 opacity and 44 tall at 640
  • .chip.cyan / .chip.vio colour the event-kind pills by role family

Event row .event-row

  • 10 apart, 8/16 padding, a divider below, 12px
  • Hover --inset
  • The newest row .flash fades in on --cyan-bg over 0.9s
