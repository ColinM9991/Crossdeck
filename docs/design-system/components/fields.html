Fields, inputs and segments .field-label, .input, .help, .seg

Form building blocks. Labels are tracked small-caps above; help text sits below; the segment control is the multi-option picker.

Notation: a/b figures are vertical/horizontal (padding, or the gap when followed by apart); radius N is a border radius in px; 13px 600 is font size and weight; 11px in --text-3 names the colour token; a bare --token is defined on the Tokens page.

States this component has: active, selected, problem; the full catalogue is on the states page.

Parts

Guard
The binding only applies while this expression is true.
A labelled mono input with help text, and the three-option segment control with its selected state.

Label .field-label

  • 11px 700, letter-spacing 0.08em, uppercase, --text-3, 8 below the input
  • The only tracked (letter-spaced) text in the system

Input .input

  • Full width, --inset background, 1px --line, radius 8, 9/12 padding, 13px
  • Placeholder in --text-3
  • .mono is 12.5px --font-mono
  • Keyboard focus moves the border to --cyan-line (the global focus ring still applies)

Help .help

  • 12px --text-3, 7 below the input, 1.5 line height
  • The editor's .guard-help.problem turns it amber when the guard names an unknown reference

Group spacing .dsec

  • Spaces field groups 18 apart

Segment .seg

  • A multi-option picker: --inset background, 1px --line, radius 8, 3 padding
  • Option buttons 6/13 padding, radius 6, 12.5px 500 --text-2
  • The selected option fills --seg-active with --text at 600
  • .seg.full makes the options equal width and centred
  • The devices page tracks the screen segments as a pressed/unpressed toggle

Select select.input

  • The input look with a chevron (the --chevron mark) at the right edge
  • The settings page sizes it 220 wide
